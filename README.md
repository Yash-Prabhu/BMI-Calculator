## Introduction

The BMI Calculator is a web-based tool that allows users to input their height and weight to calculate their BMI.
 The BMI value is then categorized to help users understand their weight status. 
This tool is intended for informational purposes and should not replace professional medical advice.

## Features

- Calculate BMI based on user-provided height and weight.
- Categorize BMI into different weight status categories.
- Simple and intuitive web interface.

## How to Use

1. Open the web application in your browser.
2. Enter your height (in feet) for entering the extra inches add a decimal point after your feet for example 5.11 represents 5 feet and 11 inches.
3. Enter your weight (in kilograms) into the respective input field.
4. Click the "Calculate" button to see your BMI and weight category.

## BMI Categories

The BMI is categorized into the following groups:

- **Underweight**: BMI < 18.5
- **Healthy Weight**: 18.5 ≤ BMI < 24.9
- **Overweight**: 25 ≤ BMI < 29.9
- **Obese**: BMI ≥ 30

Please note that these categories are general guidelines and may not apply to everyone.
 Consult with a healthcare professional for a more comprehensive health assessment.
